# Отчёт 11: единый дизайн карточек и состояние корзины

## Исправлено

- В профиле кнопка корзины больше не синяя по умолчанию.
- Обычная кнопка корзины белая и совпадает по размеру с кнопкой избранного.
- После добавления товара кнопка корзины становится тёмно-синей и увеличивается.
- Увеличение кнопки не двигает карточку или экран.
- В компактной кнопке корзины показывается только иконка, без текста.

## Единая структура карточек

Для профиля, избранного, рекомендаций корзины и каталогов применена общая визуальная структура без изменения размеров контейнеров:

1. Изображение товара.
2. Кнопки корзины и избранного справа сверху.
3. Название.
4. Отзывы.
5. Цена.

Также унифицированы белый фон карточек, светло-серый фон изображения, тёмно-синий цвет цены и стиль круглых кнопок.
